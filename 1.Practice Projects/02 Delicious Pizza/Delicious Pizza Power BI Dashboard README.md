# 🍕 Delicious Pizza Sales Dashboard – Power BI

## 📊 Project Overview

This project is a **Delicious Pizza Sales Dashboard** developed using Microsoft Power BI.

The dashboard analyzes pizza sales performance across branches, products, sales targets and daily sales performance.

The project demonstrates practical skills in **Power BI, Excel, Power Query, DAX, Data Modelling and Business Intelligence reporting**.

---

## 🎯 Project Objective

The main objective of this dashboard is to provide an interactive view of pizza business performance and help identify:

- Overall sales performance
- Branch-wise performance
- Daily sales performance
- Sales target achievement
- Product performance
- Sales trends
- Branch-level opportunities
