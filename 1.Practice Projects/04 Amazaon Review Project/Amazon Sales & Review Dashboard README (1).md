# 🛒 Amazon Sales & Review Dashboard – Power BI

## 📊 Project Overview

This project is an **Amazon Sales & Customer Review Dashboard** developed using Microsoft Power BI.

The dashboard combines sales and customer review data to provide an interactive view of business performance, product performance and customer feedback.

The project demonstrates practical skills in **Power BI, Excel, Power Query, DAX, Data Modelling and Data Visualization**.

---

## 🎯 Project Objective

The main objective of this project is to analyze Amazon sales and customer review data and identify:

- Sales performance
- Product performance
- Customer reviews
- Ratings
- Review trends
- Product-level performance
- Customer feedback patterns
- Key business KPIs
