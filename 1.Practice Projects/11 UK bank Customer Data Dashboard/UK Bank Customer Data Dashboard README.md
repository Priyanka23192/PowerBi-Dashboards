# 🏦 UK Bank Customer Data Dashboard – Power BI

## 📊 Project Overview

This project is a **UK Bank Customer Data Dashboard** developed using Microsoft Power BI.

The dashboard focuses on analyzing customer-related banking data and presenting key information through interactive Power BI visualizations.

This project demonstrates practical skills in **Power BI, DAX, Data Modelling, Data Analysis and Data Visualization**.

---

## 🎯 Project Objective

The objective of this project is to transform customer data into an interactive dashboard that can help analyze:

- Customer demographics
- Customer distribution
- Banking/customer information
- Customer segmentation
- Customer-related KPIs
- Business performance patterns
