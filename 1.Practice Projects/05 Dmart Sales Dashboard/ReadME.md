# 🛒 D-Mart Sales Dashboard – Power BI

## 📊 Project Overview

This project is a **D-Mart Sales Analysis Dashboard** developed using Microsoft Power BI.

The dashboard is designed to analyze sales performance and provide an interactive view of business data through KPIs, charts, filters and visual reports.

The project demonstrates my skills in **Power BI, Excel, Power Query, DAX, Data Modelling and Data Visualization**.

---

## 🎯 Project Objective

The main objective of this project is to transform raw sales data into an interactive Power BI dashboard that can help understand:

* Sales performance
* Product performance
* Customer/order trends
* Regional performance
* Revenue patterns
* Key business KPIs

---
