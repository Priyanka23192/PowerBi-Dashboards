# 🛒 E-Commerce Sales Dashboard – Power BI

## 📊 Project Overview

This project is an **E-Commerce Sales Dashboard** developed using Microsoft Power BI.

The dashboard analyzes e-commerce order and sales data to provide an interactive view of business performance, customer activity, product performance and sales trends.

This project demonstrates practical skills in **Power BI, Power Query, DAX, Data Modelling and Data Visualization**.

---

## 🎯 Project Objective

The main objective of this project is to transform raw e-commerce data into an interactive business dashboard that helps analyze:

- Sales performance
- Order performance
- Product performance
- Customer performance
- Regional performance
- Sales trends
- Business KPIs

---
