# 📊 DAX Functions Project – Power BI

## 📌 Project Overview

This project is focused on practicing and applying **DAX (Data Analysis Expressions)** functions in Microsoft Power BI.

The project uses **Customers** and **Orders** data to create calculations, measures and business analysis using DAX.

The main objective is to understand how DAX can be used to transform raw business data into meaningful KPIs and analytical insights.

---

## 🎯 Project Objectives

The key objectives of this project are:

- Practice commonly used DAX functions
- Create calculated measures
- Analyze customer and order data
- Calculate business KPIs
- Understand filter context
- Apply DAX calculations in Power BI
- Build interactive Power BI visuals
