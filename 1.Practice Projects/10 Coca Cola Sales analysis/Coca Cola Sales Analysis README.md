# 🥤 Coca Cola Sales Analysis Dashboard – Power BI

## 📊 Project Overview

This project is a **Coca Cola Sales Analysis Dashboard** developed using Microsoft Power BI.

The dashboard is designed to analyze sales performance and present business information through interactive Power BI visualizations.

This project demonstrates practical skills in **Power BI, DAX, Data Analysis, Data Visualization and Business Intelligence reporting**.

---

## 🎯 Project Objective

The objective of this project is to transform sales data into an interactive dashboard that can help analyze:

- Overall sales performance
- Product performance
- Regional performance
- Sales trends
- Revenue-related KPIs
- Business performance
