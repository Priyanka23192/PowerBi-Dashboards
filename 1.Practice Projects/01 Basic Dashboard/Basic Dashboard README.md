# 📊 Basic Power BI Dashboard

## 📌 Project Overview

This project is a **Basic Power BI Dashboard** created using the **Superstore dataset**.

The purpose of this project is to practice the complete Power BI reporting process, starting from raw Excel data and transforming it into an interactive business dashboard.

This project demonstrates fundamental skills in **Power BI, Power Query, Data Modelling, DAX and Data Visualization**.

---

## 🎯 Project Objective

The main objective of this project is to analyze Superstore business data and create an interactive dashboard to understand:

- Sales performance
- Profit performance
- Product performance
- Customer segments
- Regional performance
- Category performance
- Sales trends

---
